# Project Diagrams and Analysis: Bookstore & Petclinic

This directory contains source files for architectural diagrams (`.dot` files) and pre-rendered analysis images (`.png` files) for the **Bookstore** and **Petclinic** projects.

---

## 1. Diagram Source Files (.dot)

The `.dot` files contain the source code for the system diagrams, written in the DOT language. This is a plain text graph description language used by Graphviz. You can use these files to render the diagrams into various formats (like PNG, SVG, or PDF) and to modify them as needed.

### Bookstore

- `bookstore_FS.dot`: The diagram source for the few-shot Bookstore architecture.
- `bookstore_ref.dot`: The diagram source reference.
- `bookstore_zs.dot`: The diagram source for the zero-shot Bookstore architecture.

### Petclinic

- `petclinic_FS.dot`: The diagram source for the few-shot Petclinic architecture.
- `petclinic_ref.dot`: The diagram source reference.
- `petclinic_zs.dot`: The diagram source for the zero-shot Petclinic architecture.

### How to Visualize `.dot` Files

To view or render these diagrams, you can use any of the following tools:

#### a) Online Viewers (Easiest Method)
Simply copy the content of a `.dot` file and paste it into a web-based Graphviz viewer.

- **Graphviz Online:** [dreampuf.github.io/GraphvizOnline](https://dreampuf.github.io/GraphvizOnline/)
- **Viz.js:** [viz-js.com](https://viz-js.com/)

#### b) Local Software (Graphviz)
For more control, you can install Graphviz on your local machine. This will give you a command-line tool (`dot`) to convert the files.

1.  **Install Graphviz:** Follow the instructions at [graphviz.org/download/](https://graphviz.org/download/).
2.  **Run from the command line:** Navigate to this folder and run the following command to generate a PNG image:
    ```bash
    dot -Tpng bookstore.dot -o bookstore_diagram.png
    ```

#### c) IDE and Text Editor Extensions
Many popular code editors have extensions that can render `.dot` files live, directly within the editor.

- **Visual Studio Code:** Search for the extension "[Graphviz (dot) language support for Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=joaompinto.vscode-graphviz)" or similar ones.
- **IntelliJ IDEA / WebStorm:** The "[Graphviz](https://plugins.jetbrains.com/plugin/9439-graphviz)" plugin provides rendering capabilities.
