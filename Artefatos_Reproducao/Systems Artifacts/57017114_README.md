# Project Documentation: Bookstore and Petclinic

This folder contains documentation artifacts for the **Bookstore** and **Petclinic** projects. For each project, you will find a requirements file and a document describing the suggested software architecture.

---

## Bookstore Project

Artifacts related to the online bookstore system.

- `bookstore_requirements.txt`: Describes the detailed requirements for the Bookstore project.
- `bookstore_architecture.txt`: Outlines the proposed system architecture for the Bookstore.

---

## Petclinic Project

Artifacts related to the veterinary clinic management system.

- `petclinic_requirements.txt`: Describes the detailed requirements for the Petclinic project.
- `petclinic_architecture.txt`: Outlines the proposed system architecture for the Petclinic.
