# Toward Generating Microservice Architectures from Textual Requirements with Large Language Models

Welcome! This repository contains all the artifacts from a comprehensive study on generating, analyzing, and evaluating software architectures using Large Language Models (LLMs). The project uses two case studies, a **Bookstore** and a **Petclinic** system, and compares the effectiveness of **zero-shot** versus **few-shot** prompting techniques.

The study can be found here and is called `_SBCars_2025__Toward_Generating_Microservice_Architectures_from_Textual_Requirements_with_LLMs.pdf`

---

## 📁 Project Structure

The repository is organized into the following directories, each containing a specific part of the research process.

* ### `Architectural Diagrams/`
    Contains the final output images (e.g., PNG, JPG) of the architectural diagrams. These visuals were generated by the LLM for both the Bookstore and Petclinic projects using zero-shot and few-shot prompting.

* ### `Dot Files/`
    Holds the source code for the architectural diagrams in `.dot` (Graphviz) format. You can use these files to modify or re-render the diagrams. This folder also includes pre-rendered images from related analyses.

* ### `Expert Evaluation/`
    Includes all materials related to the human expert evaluation of the generated architectures. This contains the evaluation protocol, the forms used for the blind review, and the collected (anonymized) responses from the experts.

* ### `LLM Architecture Generation/`
    This is the core of the experiment. It contains the Jupyter Notebook with all the Python code for the analysis, the raw CSV data generated by the OpenAI model, and a summarized Excel file with results and charts comparing the prompting techniques.

* ### `Systems Artifacts/`
    Contains the foundational documentation for the case study systems. Here you will find the initial requirements and architectural descriptions for both the Bookstore and Petclinic projects, which served as the basis for the LLM prompts.

## Requirements to execute the project

To evaluate and run the artifacts in this repository, you'll need to meet the following technical and system requirements.

***

### 🧑‍💻 Technical Skills

* **Python Programming:** Proficiency with Python, from installation to executing scripts.
* **Development Tools:** A basic understanding of using **SSH keys**.
* **LLM Platforms:** Familiarity with the **OpenAI** graphical interface and its basic operation.
* **Python Environments:** Knowledge of how to set up and manage Python execution environments (e.g., `venv`).

***

### 🖥️ System Requirements

* **Processor:** An Intel **i3** (or equivalent) CPU or better.
* **Memory:** At least **4GB of RAM**.
* **Connectivity:** A stable **internet connection**.

## 🧭 Recommended Workflow

To get a full understanding of the project, we recommend exploring the directories in the following order:

1.  **`Systems Artifacts`**: Start here to understand the requirements of the Bookstore and Petclinic projects.
2.  **`LLM Architecture Generation`**: Dive into the Jupyter Notebook to see the core analysis and how the architectures were generated.
3.  **`Architectural Diagrams`** & **`Dot Files`**: View the final visual outputs of the generation process.
4.  **`Expert Evaluation`**: Conclude by reviewing how the generated architectures were validated by human experts.
