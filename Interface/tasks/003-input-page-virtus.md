# Task 003: Build the Input Page and VIRTUS Visual Foundation

## Objective
Create the initial page and system form using the VIRTUS visual identity.

## Files Affected

- `Interface/static/index.html`
- `Interface/static/css/styles.css`
- `Interface/static/js/app.js`

## Deliverables

- Render one system block on initial load.
- Add fields for system name, architecture target, requirements, reference services, reference interactions, and name normalization map.
- Make `Microservices` the only enabled architecture target.
- Add English labels, placeholders, descriptions, and required indicators.
- Establish CSS variables and Bootstrap 5 layout conventions for navy `#0A1E5C`, white `#FFFFFF`, light gray `#F2F2F2`, and gold `#E9C46A`.

## Acceptance Criteria

- The page opens with exactly one empty system block.
- All required fields are visible and clearly labeled in English.
- Unsupported architecture targets cannot be selected.
- Headings use uppercase text and the page uses sans-serif typography.
- The page has a responsive Bootstrap structure without real pipeline behavior.

## Dependencies

- Depends on Task 002.
